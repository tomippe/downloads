# ダウンロード（サイドパネル）

Chrome のサイドパネルでダウンロード一覧を常に表示する拡張です。

## 起動時の挙動

Chrome 起動時に「パネルを開く」タブが自動で開きます。ボタンをクリック（または Enter を押す）するとサイドパネルが表示され、タブは自動で閉じます。

一度開いたサイドパネルはタブを移動しても表示され続けます。

## ショートカットキー

- **macOS**: `Cmd + Shift + D`
- **Windows / Linux**: `Ctrl + Shift + D`

ショートカットキーでもサイドパネルを開閉できます。

## 使い方

1. Chrome で `chrome://extensions` を開き、「パッケージ化されていない拡張機能を読み込む」でこのフォルダを指定。
2. 起動時に開く「パネルを開く」タブのボタンをクリック、またはツールバーのアイコンをクリック。
3. ダウンロード一覧のアイテムをクリックで選択、ダブルクリックでファイルを開く。
4. フォルダアイコンで保存先のフォルダを開き、該当ファイルを選択表示。
